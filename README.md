# ShiftOps Assistant

A React-based internal tool designed to improve shift-based workflows in logistics teams.

## 🚀 Features

- Shift-based task management (800–804)
- Task takeover between shifts
- Status tracking (Offen, In Bearbeitung, Erledigt)
- Shift handover notes
- Reusable German email templates
- Local data persistence (localStorage)

## 🧠 Background

This project is based on my experience working in a transport/logistics company in Switzerland, where shift-based workflows and repetitive communication created inefficiencies.

- Tasks are spread across shifts
- Communication between shifts is inconsistent
- Repetitive email responses slow down workflows

## 🛠 Tech Stack

- React + TypeScript
- Zustand (state management)
- Tailwind CSS
- Vite
